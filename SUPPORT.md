# AetherSort Support and Bug Reports

This is a beta build. There is not yet a staffed support email or public issue tracker configured for the project.

## Before reporting a problem

1. Record the AetherSort version and Windows version.
2. Describe the steps that led to the issue and what you expected to happen.
3. Include the exact error message, if any.
4. Test with disposable sample files where possible.
5. Never attach private documents, credentials, personal data, or an unredacted folder listing. File paths can reveal your Windows account name, so redact them.

## Known beta limitations

- The scan is intentionally limited to regular files directly inside the selected folder. It does not recursively sort subfolders.
- File organization is local; there is no account, cloud sync, subscription, or automatic updater.
- Undo and crash recovery are best-effort safeguards, not backups.
- The beta is not yet code-signed; Windows may show a reputation warning.
- A locked file, permissions issue, or external change can stop an operation and require manual review.

## Maintainer checklist

Before publishing a public issue tracker, add a privacy-safe bug template, security reporting instructions, and a documented response process. Do not request user files unless truly necessary and consent is explicit.
